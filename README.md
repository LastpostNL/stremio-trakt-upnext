\# Trakt Up Next – Stremio addon



Standalone Stremio catalog addon that shows upcoming TV episodes using Trakt.



\## Features

\- Catalog only (no metadata, no streams)

\- Uses Trakt calendar endpoint

\- TMDB-based IDs

\- Designed to work with AIOmetadata

\- No Cinemeta



\## Install



1\. Deploy this repo on Render

2\. Add environment variables:

&nbsp;  - TRAKT\_CLIENT\_ID

&nbsp;  - TRAKT\_ACCESS\_TOKEN

3\. Install in Stremio via:

&nbsp;  https://your-app.onrender.com/manifest.json



\## Notes

\- Requires AIOmetadata addon for metadata (TMDB NL)

\- Cinemeta is not used
